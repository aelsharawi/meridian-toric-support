Support for Meridian Toric

A manual reference-photo and annotation tool. The app is free, and its core tools work offline.

Version 0.1.0 · Publisher: ahmed alshaarawy

Preclinical validation build. Use non-patient test images. This version is not validated for surgical marking, ocular registration or clinical accuracy.

Help with the app

Taking or importing a photo

Allow camera access in your device settings to use the back camera. Import selects an image through your device’s photo-selection interface. Audio is not recorded.

Checking orientation and annotations

Confirm the selected eye, image orientation, center, reference mark and entered target before saving. The phone-roll indicator measures device tilt; it does not measure ocular rotation. The app does not calculate an IOL prescription.

Saved cases and device changes

Saved photos and annotations are encrypted locally. This version has no cloud recovery, synchronization or export. Losing the device or encryption key, or deleting the app, can permanently remove access. These references do not replace the clinical record.

Using the app offline

No account or internet connection is needed for the core tools. External reference links open in your browser and need an internet connection.
